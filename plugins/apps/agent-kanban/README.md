# 📋 Agent Kanban

一个基于 PawApp 框架开发的 AI 协作看板应用，支持多智能体任务管理与自动调度。

## ✨ 特性

- 🎯 **看板式任务管理** - 5列看板（待规划、等待调度、进行中、审核中、已完成）
- 🤖 **Agent 自动调度** - 智能分配任务给可用的 Agent
- 📊 **实时进度追踪** - SSE 实时流式输出任务执行过程
- ✅ **工具调用批准** - 支持需要人工确认的工具执行
- 🔄 **拖拽操作** - 通过拖拽在不同状态间移动任务
- 👥 **Agent 视图** - 切换到 Agent 维度查看任务分布
- 🌐 **中英双语** - 自动跟随 QwenPaw 的语言设置；其他语言回退为英文

## 🚀 快速开始

### 安装

通过 QwenPaw 应用中心安装：

1. 打开 QwenPaw 应用中心
2. 搜索 "Agent Kanban"
3. 点击安装

### 使用

1. **创建任务** - 点击列标题的 `+` 按钮
2. **分配 Agent** - 在下拉菜单中选择 Agent
3. **运行任务** - 点击"运行"按钮启动执行
4. **查看结果** - 任务完成后点击"查看结果"查看详细输出
5. **拖拽移动** - 拖动卡片在不同状态间切换

## 📖 看板列说明

| 列名 | 说明 |
|------|------|
| 待规划 | 新创建的任务，等待编辑和规划 |
| 等待调度 | 已分配 Agent，等待执行 |
| 进行中 | Agent 正在执行中 |
| 审核中 | 任务完成，等待审核 |
| 已完成 | 任务已审核通过 |

## 🎨 视图切换

- **任务视图** - 按任务状态分组显示（默认）
- **Agent 视图** - 按 Agent 分组显示任务

## 🔧 技术栈

- **前端**: React + Ant Design
- **后端**: FastAPI + PawApp SDK
- **实时通信**: Server-Sent Events

## SDK 1.2 迁移试验（独立分支，尚不可发布）

本候选基于 SDK PR #8764 的 `e06b695cc`，不属于 SDK PR 的改动。

- [x] HTTP 路由、工作区选择、聊天、历史和审批改为公开 SDK。
- [x] 后台任务与最终落盘由插件资源作用域持有；审批仅处理调用者可见记录。
- [x] 看板复制到插件私有存储，保留插件目录中的旧文件。
- [x] 补充公共 HTTP 入口的持久化、真实 Runtime 派发和权限回归用例。
- [ ] 远端运行回归用例；本地不运行单测。
- [ ] 宿主提供旧 App 会话迁移后，验证原历史、审批和会话删除兼容。

**升级阻塞**：SDK 将 App 会话重新映射到用户隔离命名空间，现有公共接口无法读取或迁移旧 Kanban 会话。候选对未使用 SDK 执行的 Issue 结果返回明确的 409，原会话不删除；手动重新运行会创建新 SDK 会话。此行为用于暴露缺口，不能当作无损升级交付。

SDK 已有能力可承担新任务路径，无需增加 Kanban 专用调度接口。需要宿主解决的是有明确归属校验的旧会话迁移，而非开放任意 session 或 Manager。

静态 SDK 检查保留一项 `unmanaged-resource` 警告：文件 IO 的短生命周期等待任务使用 `asyncio.create_task`，实际线程由 `ResourceScope.run_sync` 持有；等待者取消后仍需等线程结束，才能释放文件锁。新增取消用例验证这一约束，不能通过改名或忽略扫描来消除警告。
